# Getting Started

## Creating a script

In the editor's Asset Browser, right-click → **Scripting** → **New Script**.
This writes `assets/scripts/<Name>.cscript` from a template, compiles and
registers it as a component, and opens it in the Script Editor.

A minimal script:

```cscript
class MyActor : Actor
{
    func start()
    {
    }

    func update(float delta)
    {
    }

    func physics_update(float delta)
    {
    }
}
```

- Every class must inherit from `Actor`, `Actor2D`, `Actor3D`, or another
  class that ultimately does.
- `start()` runs once when the object begins play. `update(float delta)` runs
  every frame; `physics_update(float delta)` runs once per physics step.
  Neither is required, but they're generated by the New Script template.
- Class names start with an uppercase letter and can't start with a digit.

## Attaching a script

A `.cscript` class shows up in the actor inspector's **Add Component** menu
(right-click blank space in the inspector, or the Add Component button)
under its class name, the same as any built-in component.

## Editing and recompiling

Scripts recompile automatically whenever you save from the Script Editor
(Ctrl+S, the Save button, or automatically when you press Play). Recompiling
keeps the class's identity stable, so:

- Actors already using the script keep working — you don't need to remove
  and re-add the component.
- Renaming a class updates the Add Component menu entry; the old name is
  removed.
- Fields keep their edited values across a recompile unless a field is
  removed or its type changes, in which case it re-runs its initializer.

If a `.cscript` file is added, edited, or deleted outside the editor, use
**Reload Scripts** (Asset Browser context menu) to re-scan `assets/scripts/`.
